# School Programming Assignments

This folder contains my school programming exercises and assignments. It serves as a learning workspace where I practice Python concepts, notebook-based coding, and problem solving in a structured way.

## Purpose

The files in this folder are meant to document my progress in programming during school. Each assignment is stored as a separate notebook so I can review, test, and improve my code over time.

## Naming convention

Assignments are usually named using the exercise topic and the date they were created. For example, names such as:

- `Strings110926.ipynb`
- `StringsPrint010926.ipynb`

This makes it easier to identify what the exercise was about and when i began on it.

## Project structure

At the moment, the folder includes:

- `Strings110926.ipynb` – notebook covering string-related exercises.
- `StringsPrint010926.ipynb` – notebook focused on printing and working with strings.
- `README.md` – overview of the project folder.

## How to use this folder

1. Open the notebooks in Jupyter Notebook or VS Code.
2. Run the cells in order to see the code and outputs.
3. Review the logic and try to understand how each exercise works.
4. Revisit older files later to compare progress and improve solutions.
