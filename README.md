# School Programming Assignments

This repository contains programming exercises and assignments from my schoolwork. I use it to practise Python, learn new concepts, and keep my notebooks and programs organised as I work through different topics.

Most exercises are Jupyter notebooks. They let me write code in small steps, run each part, and add notes or observations alongside the code. The phonebook exercise is a standalone Python program that stores its contacts in a JSON file.

## Purpose

The files in this repository document my progress as I learn programming. Each notebook focuses on a topic or assignment, so I can revisit the examples, understand how they work, and improve my solutions over time.

## Naming convention

Files use lowercase `snake_case`: words are written in lowercase and separated with underscores. Names describe the subject of the exercise, such as `strings_print.ipynb` or `which_type.ipynb`. File extensions show whether a file is a notebook (`.ipynb`), Python program (`.py`), or JSON data file (`.json`).

## Project structure

### Collections

These notebooks practise Python collections and data types:

- `Collections/lists.ipynb` — creating, reading, changing, and working with lists.
- `Collections/dictionaries.ipynb` — storing and looking up values with dictionaries.
- `Collections/which_type.ipynb` — recognising and working with different Python data types.

### Functions

These files practise functions and apply them in a phonebook program:

- `Functions/functions.ipynb` — function exercises, including work based on a phonebook task.
-   `Functions/Phonebook/phonebook.py` — an interactive program for adding, finding, and displaying contacts.
-   `Functions/Phonebook/phonebook.json` — the contact data loaded and saved by the phonebook program.

### Labs

These notebooks contain topic-based exercises:

- `labs/conditions.ipynb` — using conditions to control which code runs.
- `labs/strings.ipynb` — practising operations on text.
- `labs/strings_print.ipynb` — printing text and working with string output.

## How to use the files

1. Open a notebook in Jupyter Notebook or VS Code.
2. Run its cells in order and read the code and any notes or output.
3. Change the examples or try the exercises to practise the topic.
4. Run the phonebook program with Python if you want to try the interactive contact menu.

The notebooks and programs are learning exercises, so their contents may change as I practise and add to the repository.
